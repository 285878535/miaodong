# 提示音占位说明

把提示音音频文件放进**本目录**（`喵咚/Resources/Sounds/`）即可生效，**无需改任何代码**。
工程是 Xcode 文件系统同步模式，资源会自动纳入打包并扁平化到 App bundle 根目录，
代码用 `Bundle.main.url(forResource:)` 按**文件名**查找，所以只要文件名对、不重名即可。

## 文件命名约定

设置页「提示音」三个选项分别对应下面的文件名（**不含扩展名**）：

| 设置项选项 | 内部 key | 放置文件名 |
|---|---|---|
| 可爱铃声 | `default` | `alert_default` |
| 叮咚 | `ding` | `alert_ding` |
| 猫叫 | `meow` | `alert_meow` |

支持的扩展名（任选其一）：`caf` / `aiff` / `aif` / `wav` / `mp3` / `m4a`

例如放入：`alert_meow.caf`、`alert_ding.wav`、`alert_default.aiff`

## 行为说明

- **放了对应文件** → 系统通知和应用内提醒弹窗都用你的音频。
- **没放对应文件** → 自动退回系统内置音（保证有声，不会静默），方便先跑通。
- 设置页「播放提示音」开关关闭 → 通知和弹窗都不发声。

## 注意事项

- **系统通知**声音文件建议用 `.caf`、时长 < 30 秒（macOS 通知声音上限），否则系统可能改用默认音。
- **应用内弹窗**用 `NSSound` 播放，对 `wav` / `aiff` / `mp3` / `m4a` 支持都很好，时长不限。
- 发声逻辑集中在 `喵咚/Reminder/ReminderSound.swift`，如需调整命名规则改那里即可。
